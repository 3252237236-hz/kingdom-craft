# 共用场景与环境交互

版本：`shared-scene-20261009`。目标是让两个游戏的空间和交互规则互相可见；水流只是其中一种使用者。本版仍是实验性 demo，完整双向移植尚未完成。

## 本版实际接入的系统

| 系统 | 变化 | 验证范围 |
| --- | --- | --- |
| 墙面、门、地面 | 从原生物理射线采样附近表面，独立保存形状与三角面；与已有地面数据合并 | 原生几何合成包的真实 Minecraft 运行检查 |
| 移动、掉落物、生物 | Minecraft 的普通碰撞查询读取同一份原生场景 | 生物被墙挡住，掉落物停在支撑面上 |

| 射线、视线、爆炸 | 通用 vanilla clip 查询读取原生表面；投射物将原生表面视为有效命中 | 通用射线、爆炸暴露率检查 |
| 寻路 | 原生几何所在的 air 路径节点标记为障碍 | vanilla WalkNodeEvaluator 查询 |
| 水与岩浆 | 共用碰撞边界阻挡流动，开门后的新几何重排流体 tick；绕过按 block state 缓存的错误结果 | 同一对 block state 在门开关前后的运行检查 |
| 原生 NPC 的身体 | 活着的 NPC 代理参加 Minecraft 实体碰撞 | Minecraft 生物被 NPC 身体阻挡 |
| 环境与红石 | 原生 NPC 代理执行 vanilla 方块接触收集器，不再只手工触发压力板 | 仙人掌、营火、火、岩浆、溺水、灭火、压力板 |
| 药水 | 代理执行 vanilla 状态 tick 与瞬时效果，伤害、治疗进入已有原生生命桥接 | 毒、瞬间伤害、瞬间治疗、抗火 |
| 水流推力 | vanilla 计算水平流速，经原生障碍检查的位移路径转发；不扣血 | 宿主 Lua 检查弱推力和无重复伤害 |
| 死亡、读档 | epoch、传送确认与场景队列一起切换；旧包被拒绝 | 单元与宿主契约检查 |
| 攻击路径 | 按每次有效 vanilla 伤害发送来源、武器类型、标记和起点/落点，原生射线检查更近的障碍 | 宿主 Lua 与真实 Minecraft 检查；尚未验证原生剑盾相撞 |
| 受击来源 | 玩家伤害带 Henry 的原生 ID，允许受害者原生受击反应；环境和 Minecraft 生物不再假冒 Henry | 宿主契约；原生犯罪、仇恨、死亡还需验证 |
| 视觉与距离 | 投影采样校准竖直 FOV 和滚转；Minecraft 世界不重复叠加走路/受击变换；合成器修正透明雾层、边缘泄漏及重投影 | 6 项实际 Minecraft 相机、13 项 ReShade 渲染检查 |
| 接地 | 原生表面的放置落点只加数值容差，移除原来的 40 厘米偏移 | 两种小数地面高度的放置回归检查 |

## 数据链路

v11 原协议保持不变，新增可选扩展：`REN_SCENE_REQUEST=13`、`COL_SCENE_CELL=4` 和 `REN_ATTACK_TRACE=14`。场景请求携带 epoch 与最多 16 个格子坐标；回复携带单格的 ColRegion、ColBlock 与最多 256 个 ColTri。攻击包为 68 字节，包含 epoch、受害者、来源种类与 ID、标记、武器种类、有效伤害、起点/落点和击退。

宿主每格沿三个轴的正反方向发射 24 条射线，排除 living、NPC 和自己创建的 Minecraft 碰撞体。表面补片裁剪到所属格子，转换成 8×8×8 的子体素。它是采样近似，不是原生碰撞网格的完整导出。

客户端按需求请求，优先附近格子；形状和原有地面缓存分别保存，空回复只更新本链路。采样数据通常两秒后刷新，实际到达时间还受队列和帧率影响。待处理请求最多 512 个，客户端半径约 13 米、上下约 9 米；宿主限制约 15 米、上下 10 米，每帧最多两格，并在每格后检查两毫秒预算。第一个格子本身可能超过此预算，尚无实际 KCD2 帧耗时测量。

原生 API 出错、缺少法线、返回非法计数或无效坐标时不发送“空场景”，以免误删已有墙面。读档、会话离开或 epoch 更新会丢弃等待中的请求和回复。

## 验证

- Fabric 构建与 38 个 Java 单元测试通过。
- 场景几何 C++ 契约及宿主 Lua 契约通过，包括坐标转换、NPC/代理排除、缺失法线、弱流速位移、异常射线与旧会话处理。
- 实际 Minecraft 客户端在一次独立运行中通过 13 项场景、12 项环境、20 项战斗和 6 项相机检查，随后正常保存退出。
- 运行检查使用存档副本和合成原生包，`skycraft.isolatedTest=true` 阻止测试客户端连接 KCD2 或占用正式客户端互斥锁。测试 harness 不安装进正式运行目录。
- 新 shader 在实际 ReShade 6.8.0 D3D11 中通过 13 项检查，包含透明雾层、半透明颜色、前景遮挡、边缘 AA、相机转动/平移和 2 米视差。addon 未修改，沿用上一版指纹。
- 新 Minecraft 相机检查在实际 mixin 类中验证位置不缩放、2 米位移、FOV、滚转以及 world projection 不再重复晃动。手部/HUD 动画路径保留。
- 第一轮新增运行检查在相机检查通过后因 JVM 本地内存分配失败中止；保留失败记录。第二轮降低测试堆上限并采用 SerialGC 后通过全部 51 项。没有改动系统内存设置。
- **本轮没有在 KCD2 存档中验证原生射线、NPC 扣血/死亡、帧率或 D3D12 合成。`inGameVerified=false`。**

## 尚未完成

原生 NPC 主动锁定并攻击 Minecraft 生物尚未接入；Minecraft 生物攻击原生 NPC 的桥接已存在。尚无独立 Minecraft 生物攻击者的原生身份和仇恨归属。

本版已将 Minecraft 玩家攻击归因于 Henry，原生 NPC 代理互相攻击时保留原生来源；Minecraft 生物和环境来源保持未映射，不再将其错误归罪于 Henry。它们还没有可以被原生 AI 锁定的独立原生角色身份。

原生射线复查使用真实物理世界返回的最近障碍，可以拒绝经过较近碰撞体的命中。这不等于完整剑盾碰撞：骨骼挂接武器是否有可射线命中的碰撞体、目标自身各 part 的格挡状态、格挡声效及反击尚未实现。Minecraft 侧受击动画也尚未等待原生格挡回执。

原生伤害仍由 `soul.DealDamage(0, healthDamage, attacker, false, "torso")` 提交；不将昏迷当死亡，不强改角色生死或额外叠加第二个伤害接口。原生死亡和受击者识别在真实游戏中尚未确认。旧安装日志中存在 HP=1 和 death unconfirmed，不能据本版的契约通过宣称已解决。

视觉仍由两个渲染器加深度合成完成，尚未统一原生灯光、阴影和材质，也没有实际 KCD2 2 米走动录像/测量。本次确认的是相机与重投影链路不会主动缩放 2 米位移，不能将此替代真实游戏的距离验收。MC 方块仍保留整数格子；嵌入斜坡的底部应由原生深度遮住，而非任意变形方块网格。

两边的完整装备、物品、交易、材料掉落和任务系统没有统一；原生建筑、树木、地形不能因为本次采样而被 Minecraft 镐、爆炸或火焰真正破坏。没有实现原生对象的 voxel 编辑、完整动态刚体同步和维度切换。

原生 NPC 的重力和 AI 仍由 KCD2 管理。本版转发水平流速与击退，不能据此声称 NPC 的竖直弹起、游泳、蛛网减速和活塞行为已完整遵循 Minecraft。药水的 Minecraft 计算已进入代理，但原生 AI 速度等状态未统一。

## 安装与恢复

发布目录在 `E:\SkyCraftKCD2Tools\releases\shared-scene-20261009`，工具、发布和备份都使用 E 盘。安装器检查游戏及 Minecraft 都已退出，核对发布指纹，备份游戏 DLL、正式 classes/resources/src、JAR 和 Minecraft 存档，然后事务性替换并回读 SHA256。发生替换错误时恢复备份。

游戏仍从 Steam 正常启动，宿主会启动后台 Minecraft。正式启动脚本直接加载 `E:\SkyCraftKCD2Tools\fabric-src\build` 的类文件，所以安装同时更新这些目录，避免只换 JAR 而继续跑旧代码。只安装 main/client 类与资源，不安装 test 类或 harness。shader 备份后更换；原始配置、addon 和存档不会由测试副本覆盖。
