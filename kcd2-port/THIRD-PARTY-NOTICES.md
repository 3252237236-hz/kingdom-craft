# Third-party code

The KCD2 passthrough frame exporter, shared-memory mapping, and Minecraft render
mixins adapt code from
[universal-modder/examples/minecraft-gta5-passthrough](https://github.com/rehan-remade/universal-modder/tree/main/examples/minecraft-gta5-passthrough)
by Rehan and universal-modder contributors. The KCD2 host and protocol are new.
